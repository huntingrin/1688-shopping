# 网页核验

使用宿主当前可用且被允许的浏览器、MCP 浏览器或其他页面工具。若环境提供专用浏览器技能，先按其说明使用；不要硬编码技能路径、浏览器名称、页面 ID 或历史任务空间。

## 先试未登录读价

规格区常被"登录查看全部规格"遮住，但页面 DOM 里的规格列表已带每个 SKU 的价格与库存（`div.expand-view-item` 内的 `¥价格`、`库存` 文本）。先读 DOM，能拿到目标规格价就不必等登录；需要优惠价、划线价和到货运费时再登录。具体选择器见 [页面操作配方](dom-recipes.md)。

页面顶部那个"¥x.xx 起"是最低价 SKU，不是目标规格价，不要拿它当结论。

## 会话与登录

- 优先复用本任务已有的受控页面。记录宿主返回的页面/会话标识，不接管无关用户页面或其他 Agent 的空间。
- 按用户偏好保持后台执行，不抢系统焦点。登录、验证码或浏览器权限需要用户操作时，交接当前页面，说明位置和操作；用户确认后从该页面恢复。
- 不能交互的网页抓取可核对公开内容；登录区缺失就标未知。不要导出 Cookie、读登录凭证或绕过站点验证。
- 无可用浏览器时仍返回渠道候选和待核实项。不要宣称“已登录”，也不以目录服务的会话替代网页身份。
- 完成后按宿主的生命周期规则清理自己的临时页面，仅保留用户需要继续使用的结果页。

## 对每个最终候选核对

1. 商品 ID、店铺、准确 SKU（颜色/尺寸/材质/套装）、销售单位。
2. 普通采购区该 SKU 对目标数量的价格、起购量、阶梯价和库存；代发区另记。
3. 新人、首单、会员、数量或账号限定优惠是否适用；未知时不减掉。
4. 运费显示针对的地区和数量。默认地区的“包邮”或“运费起”不能当用户最终运费。
5. 决定用途适配的指标。区分产品尺寸与包装尺寸、净重与包装重、屏幕最高点与水平托盘高度；字段矛盾时列为待核实。

页面最低价可能是配件、手机款或小规格。选定 SKU 再报价；不要用混合商品页的最低数字。价格、最低数量与包邮可能同时存在渠道差异。

记录“核对时间、链接、SKU、目标数量、网页采购价、运费地区/状态、优惠条件、缺失证据”。本地证据只保存必要商品信息，避免账号姓名、电话、完整地址和订单信息。页面声明不是实物测试，图片相似不是质量证明。
